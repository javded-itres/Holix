# TUI

Полноэкранный **code-style** интерфейс (`holix tui`). Основной способ работы: чат, слэш-команды, полоса процессов, очередь промптов.

Справочник слэшей — [SLASH_COMMANDS.md](SLASH_COMMANDS.md), здесь его не дублируем.

## Запуск

```bash
cd /path/to/your/project
holix tui
holix tui -p myprofile
```

Рабочая директория сессии (`.` для tools, `run_terminal_command`, Code mode) — каталог, из которого запущен `holix tui`, а не `~/.holix/profiles/<name>/workspace`. Telegram/MAX по-прежнему используют workspace профиля. Override только в памяти, в `config.yaml` не пишется.

Веб (textual-serve; сессия на вкладку; нужен token):

```bash
uv sync --extra tui-web
holix tui --web
# http://127.0.0.1:8787/?token=...  (если --token не задан — токен в консоли)

# LAN — полный доступ к агенту; задайте надёжный token
holix tui --web --allow-lan --host 0.0.0.0 --port 8787 --token "$(openssl rand -hex 32)"
export HOLIX_TUI_WEB_TOKEN="..."
```

## Макет (сверху вниз)

| Область | Что видно |
|---------|-----------|
| **Полоса процессов** | Только **живые** фоновые серверы. Пусто — полосы нет. Клик по строке открывает лог. |
| **Todos** | Чеклист сессии из `todo_write`. Пустой список — полосы нет. |
| **Транскрипт** | Чат, tools, подтверждения |
| **Очередь промптов** | Жёлтая полоса **между** транскриптом и вводом — сообщения, пока агент занят |
| **Статус / контекст** | Режим, модель и размер последнего промпта относительно окна модели |
| **Ввод** | Многострочный промпт. Enter — отправить или направить текущий ход; Shift+Enter — новая строка |

Верхняя полоса — **не** история упавших задач. Процесс остановился или умер — строка пропадает (проверка примерно раз в 2 секунды).

## Todos

На многошаговой работе агент вызывает `todo_write` со **всем** списком (каждый вызов заменяет предыдущий). Статусы: `pending`, `in_progress`, `completed`, `cancelled`. Чеклист висит, пока есть открытые пункты. Когда все `completed`/`cancelled`, список снимается на следующем ходе пользователя (`todo_write` с пустым списком тоже очищает). `/todos` печатает его ещё раз. Это план, а не доказательство работы.

## Очередь промптов

Пока агент занят, Enter **направляет текущий ход**: Holix останавливает инструмент, который сейчас выполняется, пропускает остальные вызовы этого шага и продолжает уже с вашим текстом. Ход не дожидается конца, и это не Ctrl+S (`/stop`): `/stop` отменяет ход.

Сообщение, которое пришло после конца хода или которое ход не успел прочитать, остаётся в очереди и пойдёт следующим. `/help`, ответы на plan review и вопросы субагентов по-прежнему уходят сразу.

- Строки очереди между транскриптом и полем ввода.
- Клик по строке (или **править**) возвращает текст во ввод.
- **×** удаляет пункт без запуска.
- После текущего хода Holix выполняет очередь **по порядку**.
- Ctrl+S (`/stop`) останавливает текущий ход; очередь остаётся — можно править или удалять.

Лимит: 50 пунктов.

## Фоновые процессы

Долгая работа (сервер, бот, watch) — через `start_background_process`, не через `run_terminal_command`.

| Действие | Как |
|----------|-----|
| Лог | Клик по **верхней** строке процесса |
| Список | `/process` или `/process list` |
| Остановить сервер | `/process stop` |
| Только агент | `/stop` — серверы **не** убивает |

Если процесс **сам умер**, TUI вставляет уведомление и запускает (или ставит в очередь) ход агента — чтобы он посмотрел лог, а не крутил poll. `/process stop` автоход не стартует. Не больше трёх авто-ходов подряд, пока вы не напишете сами.

Рабочая директория: `working_directory` → workspace jail → workspace профиля. Venv в `PATH`, `PYTHONUNBUFFERED=1`.

Эти строки — **серверы всего профиля**. Конечная команда или медиазадача в этом чате — разовая фоновая задача (`run_terminal_command` с `background=true`). Результат приходит пробуждением; заметка «Background task started» не показывается как ответ. См. [TOOLS.md](TOOLS.md#разовые-фоновые-задачи).

## Индикатор контекста

Строка статуса показывает **последний промпт провайдера** (вход плюс cache read/write, без ответа) относительно окна модели. Предупреждение, что окно заполняется, не подменяет эту цифру пересчётом сохранённых сообщений. Настоящее сжатие подменяет: следующий вызов модели измеряет уже короткий промпт.

Новый ход читает сохранённый чат от первого сообщения до последнего, если в профиле не задан положительный `conversation_history_limit`. `/status` и `/compress` берут тот же диапазон. Запись сводки заменяет только те строки, которые этот ход загрузил: более ранний кусок, которого не было в памяти, остаётся в базе. `/compress` по-прежнему переписывает всю сессию.

Если чат молчал около 30 минут и заполнение уже в полосе предупреждения, следующее сообщение сначала сжимает историю, и только потом отвечает модель. Короткая сессия или сессия ниже этой полосы не сжимается. Пока ход идёт и в запрос попадают новые результаты инструментов, цифра растёт; следующее сообщение пользователя снова считается по сохранённой истории.

## Траектория

`/trace` — append-only таймлайн этой сессии (tools, финалы, фоновые процессы, todos). `/trace 80` — больше строк; `/trace search grep` — фильтр. Файлы: `~/.holix/profiles/<name>/data/trajectory/`. Стрим токенов не пишется.

## Копирование

- **Чат:** выделите текст → кнопка **Copy** внизу (⌃C/⌘C не копируют последний ответ).
- **Окно копирования (F2 / `/open`):** ⌃C / ⌘C / Ctrl+Shift+C.
- Слэш: `/copy`, `/copy tool`, `/copy all`.

## Клавиатура

| Клавиша | Действие |
|---------|----------|
| Enter | Отправить (если агент занят — направить текущий ход) |
| Shift+Enter | Новая строка |
| ↑ | Недавние промпты |
| `/` | Меню команд |
| F1 | Справка |
| F2 | Окно копирования |
| Ctrl+S | Остановить текущий ход |
| Ctrl+L | Очистить чат |

На русской раскладке macOS `,help` / `.help` работают как `/help`. `/` — **Shift+7**.
